# Pass 65 firearm visual gate

Status: project-original stylized production candidate. Final owner HITL is
still required. Real platform names are catalog labels and proportion cues;
no commercial-game mesh, texture, logo, or extracted asset is used.

The accepted M4A1 anchor defines the quality and runtime contract. Every other
platform has an independent production builder, authored anatomy receipt,
material treatment, action owner, magazine owner, sockets, and review sheet.
The checked-in specification drives the complete set, so adding a catalog
weapon without a builder or delivery fails closed.

## Mechanical release contract

- Two first-person, three world, and one independent drop GLB per firearm.
- Strict triangle descent within first-person and world LOD chains.
- Maximum 16 render primitives for first-person/world and 12 for drop; eight is
  the preferred target.
- Opaque metal and polymer PBR sets with embedded WebP textures, UVs, tangents,
  normal maps, Meshopt compression, and no external URI dependencies.
- One instance of every required signature node and socket; grip-to-muzzle and
  rear-to-front sight axes must resolve to runtime local `-Z`.
- Thirteen named action clips. The removable magazine is an intentional
  animated owner with a bounded side-of-weapon reload handoff, never debris.
- Unique source binary hashes, silhouette receipts, motion receipts, texture
  hashes, design ids, and platform-anatomy receipts across the corpus.
- Khronos glTF validation must report zero errors and zero warnings for every
  release delivery.

The deterministic six-frame sheet inside each weapon folder covers hero,
side, sight-line, reload, world LOD0, and drop LOD0 review. The corpus sheet is
`pass65-weapon-family-contact-sheet.png`. The machine-readable release receipt
is generated by `npm run qa:pass65:firearm-corpus-receipt`.

Runtime integration is gated by the all-firearm Playwright loop in
`tests/e2e/atomic-acres.spec.ts`; it verifies authored identity, bounded
renderables, triangles, actions, sockets, two-hand contacts, cache ownership,
and captures each first-person viewmodel for visual review.
