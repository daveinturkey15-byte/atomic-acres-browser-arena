# Pass 64 forging team

The team is a role contract, not permission for uncontrolled concurrent edits. One integrator owns the candidate; specialists work in isolated branches with declared file ownership and local commits. Only the integrator pushes the integration PR or invokes release workflows.

1. **Release integrator** - exact-SHA ledger, acceptance manifest, dependency order, conflict resolution, PR, protected production handoff.
2. **Best-build benchmarker** - Pass 62 immutable identities, byte/digest reproduction, Pass 63 comparator, network/performance baselines.
3. **Regression guard** - requirement-to-test matrix, Pass 62 authority preservation, cross-platform CI, independent falsification.
4. **Multiplayer authority engineer** - rematch lobby lifecycle, remote health/regen, redeploy, railgun protocol/exactly-once behavior.
5. **Renderer architect** - async `RenderRuntime`, WebGPU fail-closed identity, WebGL compatibility adapter, device-loss/readback/telemetry seams.
6. **TSL and HDR engineer** - all custom shader conversions, one linear-HDR graph, AA truth, pipeline receipts.
7. **Arena streaming engineer** - definitions, selected-only dynamic imports, abort/generation, atomic attach/rollback, disposal/memory gates.
8. **Lighting and materials reviewer** - occlusion policy, bloom depth, fog/shadows/atmosphere, coherent asset quality, per-arena budgets.
9. **Geometry and portal reviewer** - roofs/floors, door semantics, apertures, floating/orphan geometry, collision/projectile parity.
10. **Operator and weapon art guardian** - canonical rigged live/corpse parity, primitive-fallback prohibition, railgun presentation and thermal eligibility.
11. **HUD/menu/accessibility designer** - typed surface inventory, canonical map registry, responsive tactical-tech visual system, input/focus behavior.
12. **Deterministic visual and performance reviewer** - camera corpus, pixel ROIs, contact sheets, request/memory/draw/CPU/GPU budgets, immutable HITL evidence.

With four available execution slots, run at most three specialist lanes beside the integrator. Renderer architecture precedes TSL/HDR; canonical arena definitions precede streaming; gameplay authority precedes thermal presentation; typed UI inventory precedes broad restyling. Independent regression review happens after integration, not on a specialist's self-reported branch.
