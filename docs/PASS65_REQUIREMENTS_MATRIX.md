# Pass 65 Requirements, Acceptance, and Falsifier Matrix

Status vocabulary:

- `BLOCKED-P64`: implementation is prohibited until Pass 64 is independently live and frozen.
- `PLANNED`: requirement and evidence design are defined but no repo implementation exists.
- `IMPLEMENTED`: code/assets exist at a named exact SHA; this alone is not verification.
- `VERIFIED`: the listed falsifier was actively challenged and evidence is attached.
- `HITL-PENDING`: automated evidence is green; exact immutable preview awaits Dave.
- `APPROVED`: Dave approved the named exact preview SHA.
- `PUBLISHED`: protected release and public-channel evidence agree.

Every Pass 65 row starts as `BLOCKED-P64` or `PLANNED`. Nothing in this planning workspace is a gameplay implementation claim.
