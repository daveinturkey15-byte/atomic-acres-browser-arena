Each asset has id,title,assetUrl,thumbnailUrl,category,qualityRank(number; curator assessment),qualityReason,revision,authoredBy:{harness,model,effort},sourceUrls:[],license,method,limitations:[],metrics:{triangles,materials,textureBytes},sha256. URLs are deploy-base-relative (assets/...), never file paths. Thumbnail must be an actual render of that asset, not concept art. source-assets stores reconstructable Blender input when reasonable; script+parameters are required regardless.
